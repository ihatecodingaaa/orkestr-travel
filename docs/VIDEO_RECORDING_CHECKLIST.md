# Video recording checklist

Target **2:45–2:55**. Hard limit 3:00.

Script and storyboard live in `docs/SUBMISSION_PACK.md`.

---

## Before recording

- [ ] Close every personal tab
- [ ] Disable notifications (Focus / Do Not Disturb)
- [ ] Clean browser profile, or hide the bookmarks bar
- [ ] Browser zoom at 100%
- [ ] Screen at 1080p or better
- [ ] **No terminal visible** — the environment may contain credentials
- [ ] No developer console unless a beat deliberately shows it
- [ ] `npm run build && npm run start` — record against the production build
- [ ] Walk the whole flow once without recording

## The reliability point

**Nothing in this recording depends on a network.** No live research, no
unexpired Atlas offer, no authentication prompt, no clock. Everything runs from
recorded results, fixtures and deterministic engines — verified by test, so a
retake produces the same numbers.

You can film this with the Wi-Fi off.

## Before rolling

- [ ] `/demo/agent` with no query string — the clean starting state
- [ ] Provenance labels correct: `RECORDED ATLAS SANDBOX`, `RECORDED MODEL STUDIO`
- [ ] Nothing on screen claims to be live when it is recorded
- [ ] Microphone level checked, not assumed

## Beats not to rush

- [ ] The problem, in the first fifteen seconds, before any interface appears
- [ ] **"What stayed exactly as it was"** — slow down; this is the product
- [ ] The numbers — let them sit on screen
- [ ] The closing line

## Say these out loud

- [ ] **"sandbox"** when Atlas appears
- [ ] **"recorded"** when a recorded result appears
- [ ] The Tokyo / Hong Kong seam, in one sentence — do not skip it

## After recording

- [ ] Watch it end to end before uploading
- [ ] Duration under 3:00
- [ ] Audio audible throughout
- [ ] No credential, token or personal detail visible in any frame
- [ ] Record a second take as backup
- [ ] Upload per submission rules (Unlisted or Public as required)
- [ ] **Watch the uploaded version** — audio can change after processing
- [ ] Confirm the link plays in a private window
